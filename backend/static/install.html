Installer l'application

Application de supervision des performances et de la sécurité (Android 10 ou plus récent).

Chargement...

Étapes

  1. Appuie sur Télécharger l'application.
  2. Ouvre le fichier téléchargé. Si Android le demande, autorise ton navigateur à installer des applications inconnues, puis reviens en arrière.
  3. Appuie sur Installer, puis Ouvrir, et accepte les autorisations demandées.
  4. Dans l'app, va dans Paramètres → Associer ce téléphone et saisis le code à 6 chiffres fourni par l'administrateur.

Sur les téléphones Xiaomi : Paramètres → Applications → NetdataMobile → Économiseur de batterie : Aucune restriction et Démarrage automatique : activé.
